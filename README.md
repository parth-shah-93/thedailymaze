# The Daily Maze

A daily maze puzzle game. Everyone gets the same two mazes each day:

- **Trail** — find the hidden trail from start to flag in 6 tries.
- **Fog** — find the hidden flag in a fog-covered maze.

The game is a single file, `index.html`, served with GitHub Pages at https://www.thedailymaze.com.
